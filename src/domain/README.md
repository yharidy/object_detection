# domain/

This directory contains domain-specific data models and types for the object detection project.

## Contents

- `boxes.py`: 2D and 3D bounding box representations.
- `calibration.py`: Camera and LiDAR calibration data structures.
- `camera.py`: Camera-related models and intrinsics.
- `enums.py`: Enumerations for cameras, LiDARs, and object classes.
- `frame.py`: Frame data structure containing sensor observations.
- `labels.py`: Object label and annotation models.
- `lidar.py`: LiDAR-related models and data structures.
