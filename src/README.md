# src/

This directory contains the main source code for the object detection project.

## Subdirectories

- `datasets/`: PyTorch-compatible dataset classes for training and evaluation.
- `domain/`: Domain-specific data models and types.
- `models/`: Neural network architectures and model definitions.
- `sources/`: Data source handlers for different datasets (e.g., Waymo).
- `utils/`: Utility functions and helpers.
- `viz/`: Visualization tools and renderers.
